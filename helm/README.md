# generic-app Helm Chart

This is a generic, production-ready Helm chart for custom microservices.

## Features Included:
- K8s Deployment & optional Argo Rollouts
- K8s Service (ClusterIP / NodePort)
- Traefik / NGINX Ingress integration
- HPA (Horizontal Pod Autoscaler)
- ServiceAccount & ConfigMap generation
- Published as OCI Artifact to Harbor
